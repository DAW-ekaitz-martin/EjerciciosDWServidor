La respuesta cambia el DOM

JS · Ejemplo
function pintar(alumnos) {
  const lista = document.querySelector('#lista');
  lista.replaceChildren();
  for (const alumno of alumnos) {
    const li = document.createElement('li');
    li.textContent = alumno.nombre;
    lista.append(li);
  }
}
  • Creamos un nodo por cada elemento recibido.
  • textContent muestra nombres sin interpretarlos como HTML.
  • Antes de pintar el nuevo listado, retiramos el anterior.

try, catch y finally

JS · Ejemplo
async function cargar() {
  boton.disabled = true;
  estado.textContent = 'Cargando…';
  try {
    const alumnos = await obtenerAlumnos();
    pintar(alumnos);
    estado.textContent = alumnos.length ? 'Listo' : 'Sin resultados';
